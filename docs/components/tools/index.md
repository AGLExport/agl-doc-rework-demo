# AGL Development tools

Use these tools to operate an AGL demonstration and understand vehicle data exchanged by reference systems.

| Area | Guides |
| --- | --- |
| [Demo Control](demo-control/index.md) | Demo Control Panel and CARLA with AGL |

Begin with a running target from [Distributed system](../../distributed/index.md), [Small-scale integrated system](../../small-integrated/index.md), or [Large-scale integrated system](../../large-integrated/index.md). Confirm its vehicle-data topology before connecting a controller or simulator. [Use a USB CAN adapter](usb-can-adapter.md) provides supporting hardware setup.

Use the [AGL Virtual Car definition](../../virtual-car/index.md) and [CAN message definition](virtual-car/index.md) to match simulator data with the target. Return to [Development & Usage](../../development/index.md) for development routes, or [AGL Components](../index.md) for service and API specifications.
