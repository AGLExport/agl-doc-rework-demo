# Platform extension

SoDeV platform extensions add capabilities around virtualized guests and shared devices.

[Unified HMI](unified-hmi/index.md) describes Remote Virtio GPU and the Distributed Display Framework. These components connect graphical workloads to rendering and display resources, and coordinate application placement and lifecycle across systems.

Read [SoDeV architecture](../../architecture/index.md) before choosing device ownership and guest interfaces. Use the selected [workspace build](../../build/index.md) and its pinned configuration when adding an extension. The [extension reference directory](../../../../reference/platform-extensions.md) retains supporting framework and configuration links.
