# Flutter IVI demo

The Flutter IVI demo combines the `flutter-ics-homescreen` UI with infotainment functions and AGL platform services. Flutter is the main IVI toolkit described in this documentation.

Use `agl-ivi-demo-flutter` for initial evaluation. Coordinated multi-board demonstrations require explicit client/provider configuration and service placement.

- [Explore the complete demo](../../../quick-start/prebuilt/reference/flutter.md).
- [Run the prebuilt image](../../../quick-start/prebuilt/index.md).
- [Understand the homescreen](../../../components/reference-applications/flutter-homescreen/index.md).
- [Build the Basic image](../../../build/basic/image/index.md) after [setup](../../../build/basic/setup/index.md).
- [Develop a Flutter application](../../../applications/flutter/index.md).

The [upstream image recipe](https://git.automotivelinux.org/AGL/meta-agl-demo/tree/recipes-platform/images/agl-ivi-demo-flutter.bb) selects the demo applications. The [image catalog](../../../build/reference/common/reference/images.md#agl-ivi-demo-flutter) explains available variants.
