# Quick start

Start with [Run Flutter IVI demo pre-build image](prebuilt/index.md). Choose QEMU x86-64 or Raspberry Pi 4/5, download matching artifacts from the same master snapshot, and confirm that the homescreen starts.

The configured channel is **{{ agl.codename }} / {{ artifact_kind }}**. Use [Releases & migration](../../../../community/releases/index.md) to identify and record the snapshot baseline.

After evaluation, compare the [Basic and Extra demos](../portfolio/index.md), then follow [Build AGL system](../build/index.md) to create your own image. Read [AGL Components](../components/index.md) for individual application and service explanations, then use [Application development](../applications/index.md) for Flutter and Qt workflows.
