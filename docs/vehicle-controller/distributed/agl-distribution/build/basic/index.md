# Basic AGL system

Build an IVI-family Flutter or Qt demo, including the IVI-derived Flutter Cluster.

1. [Setup build environment](setup/index.md): prepare the host, obtain source, and select features.
2. [Build target image](image/index.md): choose the actual recipe and inspect its artifacts.
3. [Deploy to board](deploy/index.md): write or launch the image and check runtime behavior.

Review the [Basic demo system](../../portfolio/basic-demo/index.md) and [Basic architecture](../../architecture/basic-demo/index.md) first. Use a separate build directory when changing machine or profile features. See [Supported the other boards](../other-boards/index.md) for additional target requirements.
