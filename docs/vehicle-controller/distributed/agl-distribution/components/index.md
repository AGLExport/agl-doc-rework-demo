# AGL Components

This chapter of [AGL Distribution](../index.md) explains reference implementations, platform services, application lifecycle, and APIs. Use these specifications when developing or customizing a distributed AGL system.

- [AGL Reference Applications](reference-applications/index.md).
- [AGL Services](services/index.md).
- [IVI Application Framework](application-framework/index.md).
- [AGL API](api/index.md).

For implementation changes, continue with the sibling chapters [Platform Customize](../customize/index.md) or [Application development](../applications/index.md).

Build and deploy a system first through [AGL Distribution](../index.md), [Small-scale integrated system](../../../small-integrated/index.md), or [Large-scale integrated system](../../../large-integrated/index.md). System-specific extensions are under [SoDeV](../../../large-integrated/sodev/components/platform-extensions/index.md) and [Container integration](../../../small-integrated/container-integration/components/platform-extensions/index.md).

Use [AGL Development tools](../../../../development/tools/index.md) for demo control and vehicle-signal definitions. The supporting [component directory](reference/source-directory.md) links additional implementation material.
