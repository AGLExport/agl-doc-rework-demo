# Architecture

Architecture describes what runs in each demo and how applications reach platform services and devices. Choose the matching group before modifying recipes or runtime configuration.

- [Basic AGL system](basic.md): the IVI/compositor family with Flutter or Qt.
- [Extra AGL system](extra.md): dedicated Qt/Slint clusters and the Momi IVI container guest.

These groups describe software composition. For the placement of ECUs in a vehicle, use [AGL Artifact](../../home/index.md). For virtual machines and container hosts, use [AGL integrated system](../../integrated/index.md).

The supporting [AGL system architecture overview](../../home/architecture.md) and [Yocto layer guide](../build/common/layers/overview.md) describe broader platform and source-layer relationships.
