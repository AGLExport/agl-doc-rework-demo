# AGL glossary

| Term | Meaning | Read next |
| --- | --- | --- |
| AGL | Automotive Grade Linux, the collaborative automotive Linux platform. | [About AGL](../explanation/about-agl.md) |
| UCB | Unified Code Base, the shared AGL software base. | [Architecture](../explanation/architecture.md) |
| IVI | In-Vehicle Infotainment. | [Image targets](images.md) |
| IC | Instrument Cluster. | [IC profile](../develop/demos/instrument-cluster.md) |
| BSP | Board Support Package: the board-specific software and build configuration. | [Hardware support](hardware.md) |
| MACHINE | Yocto target-machine configuration selected for an AGL build. | [Build initialization](../develop/platform/initialize-build.md) |
| Image target | BitBake target that defines a system image's contents. | [Image targets](images.md) |
| Feature | AGL configuration selected through aglsetup.sh. | [Build initialization](../develop/platform/initialize-build.md) |
| Layer | A collection of Yocto recipes and configuration. | [AGL layers](build/layers/overview.md) |
| Recipe | Build metadata describing how software is fetched, built, and packaged. | [Create a recipe](../develop/platform/custom-recipe.md) |
| SDK | Software Development Kit matched to a target image. | [SDK workflow](../develop/apps/sdk-overview.md) |
| Build host | The Linux system running the image/application build tools. | [Host and target](../explanation/build-and-runtime.md) |
| Target | The board or virtual machine running AGL. | [Choose an environment](matrix.md) |
| Snapshot | A development build that can change between downloads. | [Release guidance](../releases/index.md) |
