# AGL glossary

| Term | Meaning | Read next |
| --- | --- | --- |
| AGL | Automotive Grade Linux, the collaborative automotive Linux platform. | [About AGL](about-source.md) |
| UCB | Unified Code Base, the shared AGL software base. | [Architecture](architecture.md) |
| IVI | In-Vehicle Infotainment. | [Image targets](../standalone/build/common/reference/images.md) |
| IC | Instrument Cluster. | [IC profile](../integrated/containers/build-guide.md) |
| BSP | Board Support Package: the board-specific software and build configuration. | [Hardware support](../standalone/build/common/reference/hardware.md) |
| MACHINE | Yocto target-machine configuration selected for an AGL build. | [Build initialization](../standalone/build/common/initialize-build.md) |
| Image target | BitBake target that defines a system image's contents. | [Image targets](../standalone/build/common/reference/images.md) |
| Feature | AGL configuration selected through aglsetup.sh. | [Build initialization](../standalone/build/common/initialize-build.md) |
| Layer | A collection of Yocto recipes and configuration. | [AGL layers](../standalone/build/common/layers/overview.md) |
| Recipe | Build metadata describing how software is fetched, built, and packaged. | [Create a recipe](../standalone/customize/recipe.md) |
| SDK | Software Development Kit matched to a target image. | [SDK workflow](../standalone/applications/sdk-overview.md) |
| Build host | The Linux system running the image/application build tools. | [Host and target](build-and-runtime.md) |
| Target | The board or virtual machine running AGL. | [Choose an environment](../standalone/build/common/reference/matrix.md) |
| Snapshot | A development build that can change between downloads. | [Release guidance](../releases/index.md) |
