# In-Vehicle Infotainment

AGL provides an In-Vehicle Infotainment (IVI) platform with demo software. Reference images combine a homescreen, applications, graphics, audio, and vehicle-data access to demonstrate the cabin user experience.

The platform supports multiple GUI toolkits. Flutter is the current mainstream toolkit for AGL IVI, and Qt 6 is also supported. Select the toolkit and image profile together so that the required application runtime and services are present.

| Toolkit | Demo and development guides |
| --- | --- |
| Flutter | [Flutter IVI demo overview](../../start/prebuilt/flutter.md), [Flutter IVI build](../../standalone/build/ivi/flutter.md), and [Flutter application development](../../standalone/applications/flutter.md) |
| Qt 6 | [Qt IVI build](../../standalone/build/ivi/qt-ivi-demo.md), [Qt IVI homescreen](../../components/applications/qt-homescreen.md), and [Qt application development](../../standalone/applications/qt.md) |
