# In-Vehicle Infotainment

In-Vehicle Infotainment (IVI) covers the vehicle's infotainment user interface and its supporting services. AGL's reference images bring a homescreen, applications, graphics, audio, and vehicle-data access together.

Choose the [Flutter IVI demo](../../start/prebuilt/flutter.md) for an introductory walkthrough. For a source build, select [Flutter IVI demo](../../standalone/build/ivi/flutter.md) or [Qt IVI demo](../../standalone/build/ivi/qt-ivi-demo.md). The [image catalog](../../standalone/build/common/reference/images.md) describes their packages and variants.

Application implementation is documented separately under [AGL Reference Applications](../../components/applications/index.md).
