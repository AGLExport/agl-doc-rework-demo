Getting help

If you are looking for something to work on, or need some expert assistance in
debugging a problem or working out a fix to an issue, our community is always
eager to help. We hang out on various developer meetings,
discord (https://discord.gg/XSanZxJ7k4) and the mailing lists.
We will be glad to help just mind timezones and stay on the channel.
The only silly question is the one you don't ask.
Questions are in fact a great way to help improve the project as they highlight
where our documentation could be clearer.

Here are a few links:

https://docs.automotivelinux.org/        # documentation site
https://lists.automotivelinux.org/       # mailinglists and calendar
https://wiki.automotivelinux.org/        # old style wiki
https://jira.automotivelinux.org/        # bugtracker
https://confluence.automotivelinux.org   # confluence
https://discord.gg/XSanZxJ7k4            # discord server
