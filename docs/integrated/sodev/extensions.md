# Platform extension

SoDeV platform extensions add capabilities around virtualized guests and shared devices.

[Unified HMI](../../components/extensions/unified-hmi.md) describes Remote Virtio GPU and the Distributed Display Framework. These components connect graphical workloads to rendering and display resources, and coordinate application placement and lifecycle across systems.

Read [SoDeV architecture](architecture.md) before choosing device ownership and guest interfaces. Use the selected [workspace build](build.md) and its pinned configuration when adding an extension. The [extension reference directory](../../components/extensions/index.md) retains supporting framework and configuration links.
